## Pre-requisite:
Basic knowledge of Computer Fundamentals; Co-requisite: Web Technology (BCA-WT301)

---

## Course Objectives:
1. To provide hands-on experience in setting up a web development environment and working with HTML to create structured web pages.
2. To develop practical skills for styling web pages using CSS including layouts, responsiveness, and animations.
3. To familiarize students with the Bootstrap 5 framework for building responsive and component-rich websites.
4. To enable students to integrate HTML, CSS, and Bootstrap to develop complete, multi-page static websites.

---

## Course Outcomes:
After completion of the course, the student will be able to:

1. **CO1:** Create well-structured and semantic web pages using HTML5 tags including forms, tables, lists, and multimedia elements.
2. **CO2:** Apply CSS styling techniques including selectors, box model, Flexbox, Grid, media queries, and animations to design responsive web pages.
3. **CO3:** Build responsive and interactive web interfaces using Bootstrap 5 components such as Navbar, Cards, Modals, Carousel, and Forms.
4. **CO4:** Develop and deploy a complete multi-page static website by integrating HTML5, CSS3, and Bootstrap 5.

## List of Practicals *(Indicative & not limited to)*

---

### HTML-Based Experiments

1. Set up a local web development environment (VS Code / Notepad++), create a basic HTML page and observe the output in a browser using browser developer tools (Inspect, Console).
2. Create a web page demonstrating all HTML text formatting tags — headings (h1–h6), paragraphs, bold, italic, underline, superscript, subscript, blockquote, and pre-formatted text.
3. Design a web page using HTML lists (ordered, unordered, and nested lists) and hyperlinks (internal, external, and email links with target attributes).
4. Create an HTML page embedding images, audio, and video with proper attributes (src, alt, controls, autoplay, loop) and demonstrate image linking.
5. Design an HTML table for a student result sheet using `<table>`, `<tr>`, `<th>`, `<td>` with `colspan`, `rowspan`, and table attributes (border, cellpadding, cellspacing).
6. Create a student registration form using HTML form elements — text, email, password, radio buttons, checkboxes, dropdown (`<select>`), textarea, and submit/reset buttons with GET/POST methods.
7. Build a complete web page layout using HTML5 Semantic elements — `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.

---

### CSS-Based Experiments

1. Create a web page demonstrating all three types of CSS (Inline, Internal, External) and apply various CSS selectors (universal, element, class, ID, pseudo-class, and pseudo-element).
2. Design a styled web page applying CSS text and font properties — font-family (Google Fonts), font-size, font-weight, text-align, text-decoration, letter-spacing, and line-height.
3. Demonstrate the CSS Box Model (content, padding, border, margin) by designing a styled card layout with `box-sizing`, background colors, and border-radius.
4. Design a multi-section webpage using CSS Flexbox — implement navigation bar, image gallery, and footer layout using `justify-content`, `align-items`, `flex-wrap`, and `flex-direction`.
5. Create a responsive grid-based web page layout using CSS Grid — implement a magazine-style layout with header, sidebar, main content, and footer using `grid-template-columns`, `grid-area`, and `gap`.
6. Design a fully responsive webpage using CSS Media Queries — create a layout that adapts seamlessly across mobile (< 576px), tablet (576px–992px), and desktop (> 992px) screen sizes.
7. Create a CSS animation showcase page demonstrating `transition` effects on hover (buttons, cards) and `@keyframes` animations (bouncing ball, rotating loader, fading text).

---

### Bootstrap 5-Based Experiments

1. Create a responsive webpage using the Bootstrap 5 Grid System — demonstrate containers, rows, columns, breakpoints (sm, md, lg, xl), column offsets, and nested grids.
2. Design a responsive Navigation Bar using Bootstrap 5 Navbar component with a brand logo, nav links, dropdown menu, search form, and toggler button for mobile view.
3. Build a product showcase page using Bootstrap 5 Cards — implement card with image, title, description, button, card groups, and card with header and footer.
4. Create a responsive web page using Bootstrap 5 Form components — implement form controls, floating labels, input groups, radio/checkbox, select dropdown, range slider, and form validation feedback (valid/invalid states).
5. Design a web page demonstrating Bootstrap 5 UI Components — implement Alerts (dismissible), Badges, Buttons (all variants), Button Groups, Progress Bars, and Spinners.
6. Build an interactive web page using Bootstrap 5 Modal, Accordion, Tabs, and Tooltip/Popover components — demonstrate triggering events and dynamic content.
7. Create an image slider / banner section using Bootstrap 5 Carousel with controls, indicators, captions, and auto-play feature; also implement a responsive Bootstrap Table (striped, bordered, hoverable, responsive).

---

### Integrated Project Experiment

1. Develop a complete **4–5 page responsive static website** (e.g., College Club Website / Personal Portfolio / Product Landing Page) by integrating HTML5, CSS3, and Bootstrap 5 — incorporating:
   - Responsive Navbar with mobile toggler
   - Hero / Banner Section with CSS animation
   - About Section with Bootstrap Cards
   - Services / Skills Section using Grid layout
   - Contact Form with Bootstrap validation styles
   - Footer with social media links and Bootstrap Icons
   - Deployment on GitHub Pages
